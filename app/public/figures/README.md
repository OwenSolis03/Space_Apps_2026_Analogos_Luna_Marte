# Figures

The control maps from the EDA (FIG.001 to FIG.005) are produced on Yuca and are not in the repository.

To show one on the Data page:

1. Copy the PNG into this folder, for example `public/figures/map_earth_mean_slope_deg.png`.
2. In `src/content/eda.ts`, set the `src` of its entry in `FIGURES` to `"figures/<file name>"`.

Until then the page shows a placeholder frame with the figure caption.
