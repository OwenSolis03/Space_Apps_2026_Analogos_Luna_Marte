Marcador de imagen pendiente: caja de 1px con aspas y un pie de figura en mini mono.

**El consumidor aporta**
- `ratio` como proporción CSS (`16 / 9`, `3 / 4`, `1 / 1`) y el ancho del contenedor.
- `label` con la descripción de la imagen definitiva, que se lee como nombre accesible.
- `caption` con un código de figura (`FIG.003`) y su descripción.

**Cuándo usar**
- En maquetas y plantillas, donde irá una imagen más adelante.

**Qué evitar**
- Dejarlo en una pantalla final: sustitúyelo por la imagen y conserva el pie de figura.
