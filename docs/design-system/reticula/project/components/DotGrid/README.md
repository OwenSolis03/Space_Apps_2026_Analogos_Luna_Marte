Retícula decorativa de puntos cuadrados de `dot-size` cada `dot-pitch`, con una barra naranja guía opcional.

**El consumidor aporta**
- `cols` y `rows`; el tamaño del punto y el paso no cambian.

**Cuándo usar**
- Para separar bloques o llenar el borde de un panel; tres filas es la medida habitual.
- `tone="faint"` cuando la retícula va detrás de contenido.

**Qué evitar**
- Hacer retículas de más de seis filas: pasan a ser textura y compiten con el contenido.
- Esperar que se anuncie: es decorativa.
