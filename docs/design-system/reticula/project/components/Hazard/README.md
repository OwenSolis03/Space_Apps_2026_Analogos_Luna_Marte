Banda decorativa de rayas a 45° en grafito o en naranja, sin significado propio.

**El consumidor aporta**
- El ancho (por defecto 100% del contenedor) y `height` si no quiere los 24px.
- Una etiqueta de texto junto a la banda cuando deba indicar peligro; la banda es decorativa y no se anuncia.

**Cuándo usar**
- Como cierre de una barra, de una lectura o de un panel.

**Qué evitar**
- Más de una banda por composición.
- Poner texto encima de las rayas.
