Bloque de titular con una regla superior, etiqueta de sector, titular en mayúsculas display, subtítulo en naranja legible y firma.

**El consumidor aporta**
- `title` obligatorio; `kicker`, `subtitle` y `by` son opcionales.
- `as` con el nivel de encabezado correcto del documento (`h1` solo una vez).
- `size`: `lg` para la portada, `md` para secciones, `sm` para tarjetas.

**Cuándo usar**
- Al abrir una lámina, una sección o un panel grande.
- `rule="graphite"` cuando el naranja ya domina la zona.

**Qué evitar**
- Titulares de más de tres líneas.
- Dos `lg` en una misma vista.
- Cambiar el color del subtítulo a `signal`: sobre claro no llega a 3:1.
