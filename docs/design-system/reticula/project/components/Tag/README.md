Etiqueta compacta de estado en mini mono, rellena de grafito, de naranja o con contorno.

**El consumidor aporta**
- Un texto de una a tres palabras en `children`; el componente lo pone en mayúsculas.
- `bracket` cuando el estado es una anotación y no un valor de una lista.

**Cuándo usar**
- `graphite` para el estado normal, `signal` para el que requiere atención, `outline` para un estado secundario.

**Qué evitar**
- Comunicar el estado solo con el tono: la etiqueta ya trae la palabra, no la sustituyas por un punto de color.
- Texto de más de tres palabras: pasa a un `Readout`.
