Barra modular de 24px con marco de `stroke-line` y segmentos de anchos desiguales; es ornamento y no codifica datos.

**El consumidor aporta**
- El ancho del contenedor.
- `segments` opcional: una lista de anchos relativos; los lugares pares se rellenan y los impares quedan vacíos.

**Cuándo usar**
- Como base de un panel o de una lectura, junto a un código (`PLS SCN`).

**Qué evitar**
- Un campo de líneas finas que se estrechan hacia un borde: usa pocos segmentos y gruesos.
- Una segunda barra en la misma zona.
