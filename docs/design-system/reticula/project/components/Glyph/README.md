Marca de instrumento dibujada en SVG sobre una rejilla de 24px: miras, tics, esquinas, barras oblicuas, chevrones y puntos.

**El consumidor aporta**
- `name` entre los doce disponibles y `size` en píxeles.
- `label` solo si el glifo es la única señal de algo; sin `label` es decorativo y no se anuncia.

**Cuándo usar**
- Dentro de `IconButton`, como marca de borde de una composición y junto a un titular.
- `tone="signal"` solo como adorno junto a un elemento que ya dice lo mismo con texto.

**Qué evitar**
- Comunicar significado con una marca naranja sola sobre `surface` (1,8:1).
- Añadir pictogramas ilustrativos o emoji: si falta uno, dibújalo con líneas finas, huecos y ángulos de 45°.
